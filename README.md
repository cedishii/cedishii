### Consulta: Academic Consultation Booking System 
![Next.js](https://img.shields.io/badge/Next.js-16-000000?style=flat&logo=nextdotjs&logoColor=white)
![React](https://img.shields.io/badge/React-19-61DAFB?style=flat&logo=react&logoColor=black)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat&logo=typescript&logoColor=white)
![Express](https://img.shields.io/badge/Express-5-000000?style=flat&logo=express&logoColor=white)
![Node.js](https://img.shields.io/badge/Node.js-339933?style=flat&logo=nodedotjs&logoColor=white)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4479A1?style=flat&logo=postgresql&logoColor=white)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=flat&logo=tailwindcss&logoColor=white)

My capstone project — a consultation booking platform for Mapúa University's School of Information Technology. Students book advising slots with professors, professors manage availability and log outcomes, and admins oversee approvals, calendars, and reporting.

**Key Features:**
- Role-based booking with account-approval gating — students book, professors set availability, admins monitor everything
- Auto-generated digital advising slips (pre-filled PDFs) with proof-of-evidence upload and resubmission tracking
- Reschedule, cancellation, and notification flow with correct actor attribution
- AI-assisted FAQ chatbot (Groq / Llama 3.1) that recommends professors by concern type and answers booking questions
- PDF/Excel exports of consultation history plus admin analytics (professor & topic breakdowns)
- Academic calendar integration with term/week tracking and countdown timers

**My Role — Full-Stack Developer (end-to-end):**
- Architected and built the entire system: Next.js frontend, Express backend, and PostgreSQL schema
- Implemented JWT + bcrypt auth with httpOnly cookies, role-based access control, and security hardening (Helmet, rate limiting, input validation)
- Built the PDF/Excel generation pipeline (PDFKit, pdf-lib, ExcelJS) for advising slips and reports
- Integrated the Groq-powered chatbot, Cloudinary file storage, and Brevo email delivery

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS, Radix UI, Recharts, Express 5, Node.js, PostgreSQL, JWT, Groq (Llama 3.1), Cloudinary, Brevo, PDFKit / ExcelJS

🔗 [View Repository](https://github.com/GeeCyy/ConsultSiya)

A team-built platform that detects fake news and verifies claims through reliable sources using the Google Gemini 2.5 Pro API and Google Custom Search API.

**Key Features:**
- Real-time AI fact-checking with Google Gemini for advanced NLP
- Multi-format content verification (Text, URL, Image with OCR)
- Automated evidence gathering from credible news sources
- Admin dashboard with comprehensive audit logging
- JWT-based authentication with role-based access control

**My Contributions (Developer — Verification History):**
- Built user-scoped backend retrieval endpoints for verified news history records
- Implemented server-side filtering & search endpoints, integrated with the Angular history UI
- Added authorization checks to ensure users can only access their own history data

**Tech Stack:** Java 17, Spring Boot, Spring Security, JPA/Hibernate, PostgreSQL, Angular, Tailwind CSS, Google Gemini API, Docker
